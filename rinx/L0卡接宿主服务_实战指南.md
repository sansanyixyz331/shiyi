# L0 卡片调用宿主服务 · 实战指南

> 面向：写 **L0 卡**（`page.card`）且需要调**宿主服务**（`octos.*` / `matrix.*`）的人。
> 依据：官方源码（`hagency-org/Rinx`）+ 官方工具实测（2026-10-04）。上游反馈见
> [OctoSense-org/OctoScript-App-Design-Flow#150](https://github.com/OctoSense-org/OctoScript-App-Design-Flow/issues/150)。
> 本文只写**官方文档没有、且会 fail closed** 的那几处。

---

## 0. 一句话

**脚本应用**（`main.splash`）有语句，自己调 `host.request(...)`；
**L0 卡**（`page.card`）是声明式的、没有语句 —— 它在**同级 `bindings.json`** 里声明"打开/某事件时调哪个服务、结果写进哪个数据槽"，**由宿主执行**。

> 源码原话（`Rinx` `src/miniapps/package.rs`）：
> `main.splash apps call host.request directly; bindings.json is for L0 cards`

---

## 1. bundle 里多一个文件

```
bundle/
  manifest.json      # capabilities 里必须声明你用到的服务
  page.card
  page.data.json     # ★ 必须预置 target 占位（见 §3）
  kit/
  bindings.json      # ★ L0 卡特有的能力接线
  assets/icon.svg
  screenshots/
```

## 2. `bindings.json` 的形状

```json
{
  "on_open": [
    { "service": "octos.session.open", "target": "session" },
    { "service": "octos.turn.start",   "target": "reply",
      "args": { "text": "这句话还缺什么？" } }
  ],
  "events": {
    "confirm": { "service": "matrix.send_message", "target": "sent",
                 "args": { "text": "已确认。" } }
  }
}
```

| 约束 | 值 |
|---|---|
| `on_open` | 打开卡片时执行，**≤ 8 条** |
| `events` | 卡片触发该事件时执行，**≤ 64 条** |
| `service` | **必须**已在 `manifest.capabilities` 里声明，否则**拒绝导入**（`<service> is not declared in capabilities`） |
| `target` | **顶层数据名**，只允许 `[A-Za-z0-9_]` |
| `args` | 必须是一个 object；可写 `{"$state":"field"}` / `{"$data":"/json/pointer"}` / `{"$value":true}` |
| 脚本应用 | **不得**有 bindings（会被拒） |
| `manifest.agent` | 这个宿主不支持；改声明显式 `octos.*` |

结果写回**卡片数据**的 `target` 槽：

```json
{ "is_ok": true,  "data": { … } }
{ "is_ok": false, "error": "…" }
```

## 3. 卡片侧：三步，缺一不可

```text
# ① 用 state 声明一个根名（名字 = bindings 里的 target）
state reply { shape: text }

# ② 按点号路径取服务返回的数据
Note(instance: "reading", text: reply.data.text)
```

```json
// ③ page.data.json 里必须预置同名占位
{ "reply": { "is_ok": true, "data": { "text": "（等应答…）" } } }
```

**为什么第 ③ 步必须**：卡片在**任何调用返回之前**就先被 lower 一遍。此时 `reply` 不存在
→ 路径解析不到 → **整张卡 lower 失败**：

```
unresolved or unsupported kit property
```

预置占位后：首帧显示占位，服务回来后宿主**覆盖** `data["reply"]` 并重绘 ⇒ 文字自动更新为真答复。

---

## 4. 失败语义：三条，全都 fail closed

| # | 情况 | 结果 | 对策 |
|---|---|---|---|
| 1 | **`target` 没预置** | **整卡** lower 失败（`unresolved or unsupported kit property`） | `page.data.json` 预置占位（§3） |
| 2 | **调用失败**（无 provider / 拒权 / 网络错）→ 宿主写 `{"is_ok":false,"error":…}`，**没有 `data`** | 同上，**整卡** lower 失败（不是只少一行） | 动态行包一层**裸布尔 guard**：`when reply.is_ok { … }` |
| 3 | **`on_open` 任一调用失败** | **整个应用打不开**（停在导入表单，无报错） | 别在 `on_open` 里挂宿主未必具备的服务；能延后就延后到 `events` |

第 3 条的源码依据（宿主 `run()`，`Rinx` `src/miniapps/ui.rs`）：

```rust
self.render(cx)?;                                    // 首帧 lower 失败 → 到此返回
for call in calls {
    self.binding(cx, call, "root", &Value::Null)?;   // 任一 on_open 失败 → 到此返回
}
self.view.view(cx, ids!(app_content)).set_visible(cx, true);   // 只有全成功才走到这
self.view.view(cx, ids!(import_form)).set_visible(cx, false);  // 表单才会被隐藏
```

**⇒ 结论**：一个用宿主服务的 L0 卡，**比不用服务的卡更脆弱**；"不依赖服务也完整可用"
（`card-host` 场景的官方要求）**通过 binding 这条路是做不到的**，必须靠上面的 guard + 预置。

## 5. 检查清单（提交前逐条过）

> **⚡ 一键过**：本仓 [`tools/l0_bindings_lint.py`](../tools/l0_bindings_lint.py) 把下面几条实现成了检查器
> ——`python3 tools/l0_bindings_lint.py <bundle_dir>`，退出码 0 = 通过。前后对照见 [`tools/证据/`](../tools/证据/)。

- [ ] 用到的每个服务，都在 `manifest.capabilities` 里**精确名**声明（前缀不授权）
- [ ] `on_open` ≤ 8、`events` ≤ 64
- [ ] 每个 `target` 都在 `page.data.json` 里**预置了占位**
- [ ] 每个读 `target.data.*` 的动态行，都包在 `when <target>.is_ok { … }` 里
- [ ] `on_open` 里没有"宿主可能不具备"的服务（否则应用打不开）
- [ ] 改完字节后**重算摘要**：`rinx-miniapp-package <bundle_dir>`
- [ ] 跑一遍官方门禁：`hub check --allow-unsigned` → `PASSED`
- [ ] 真跑一次：既看**成功**（有真答复），也看**失败**（服务挂/无 provider 时不崩、不给"假成功"）

## 6. 一张表看清两条路

| | 脚本应用 `main.splash` | L0 卡 `page.card` |
|---|---|---|
| 怎么调 | `host.request(service, args, fn(r))`，代码里的**语句** | 同级 `bindings.json` **声明** |
| 结果 | 回调参数 `r.is_ok` / `r.data` / `r.error` | 写进卡片数据槽 `target`，卡按路径读 |
| 状态 | 脚本自己管 | state 声明 + `page.data.json` 预置 |
| 失败行 | 自己 `if/else` | `when X.is_ok { … }` guard |
| bindings | **不许用** | **只有它用** |
