## 生成与合成

```sh
# 1. 生成 8 段语音（edge-tts）
python build/make_narration.py

# 2. 按时间点拼接（段间补静音）并混流进原片
#    视频轨 -c:v copy，不动画质；原片无音轨，直接加
python build/make_narration.py --mux
```

产物：脚本输出 `build/_video/shiyi-walkthrough-narrated.mp4`
落地：**已接为主片** `build/_video/shiyi-walkthrough.mp4`（有声版）；
原无声版留档 `build/_video/shiyi-walkthrough-silent.mp4`，两个版本都在仓内，可对照。
