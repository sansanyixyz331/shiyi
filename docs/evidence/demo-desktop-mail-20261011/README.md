# 桌面端 · 「邮件来了它自己读到」· 实证 + 演示片

> **2026-10-11/12 · Windows 桌面 · OctoSense 参考宿主 + 系统 app `os.shiyi` 0.3.11**
> 本目录证四件事：**① 外面真发来一封工作邮件 ② 它自己读到（不点、不打字）③ 抽出时间地点钉成常驻卡 ④ 到点主动来找你，并把那句话念出来**。

---

## 1. 这份证据要回答的质疑

**"邮件是不是你们自己敲进去的？"** —— 不是。演示里那封信是**用 SMTP 真投递**进邮箱的（本机 → 163 邮件服务器 → 宿主自己收）。
**"是不是要人点一下它才读？"** —— 不是。应用**自己每隔 10 秒看一次邮箱**，界面上写着「自动读邮件：开 · 收件箱 N 封」。
**"真的念了吗？"** —— 念由**系统语音**完成，日志留证：`desktop_speak: 系统 TTS 已念完（退出码 0）`（截图 `03` 同屏可见）。

---

## 2. 链路（谁做什么）

| 步 | 谁 | 做什么 |
|---|---|---|
| ① | 外部 | 用 SMTP **真投递**一封工作邮件 |
| ② | 应用 `os.shiyi` | **自己轮询**收信（先 sync 再列，只处理没处理过的；首启只登记基线） |
| ③ | 宿主 | 提供 `mail.*` 服务（凭证由宿主保管，应用只拿元数据与正文） |
| ④ | 应用 + 助手 | 读正文，抽出**时间 / 地点 / 要提醒什么**，钉成一张**常驻卡**（快览屏） |
| ⑤ | 宿主 | 到点主动来找你：**弹提示 + 把那句话念出来**（系统语音） |

## 5. 如实说明

- **"到点"用了演示压缩**：提醒的**规则、提前量、到时说的话**都是真的，只是把"等到那一刻"在演示里压短（否则要等一整天）。
- **应用要宿主提供邮件服务**：宿主没有 `mail.*` 时，应用**如实标注**、不假装（fail-closed）。
- **不改动、不外传**：全程在本机读信；卡片上显式标注来源；没有把内容送到任何第三方服务。
