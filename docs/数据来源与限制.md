# 数据来源与限制 · 拾意 Pickup

> 官方《作品提交与 App Hub》第 4 项要求：**数据来源、申请权限、隐私处理，
> 以及用户授权、拒绝和失败时的行为**；本文件即《数据来源与限制》交付物。
> 本文件逐条写清，**与 `src/` 代码和 `bundle/manifest.json` 的事实一一对应**。

---

## 1. 数据来源（卡上每个事实的来处）

| 卡上的事实 | 来源 | 处理方式 | 代码 |
|---|---|---|---|
| 消息原文 / 房间 / 时刻 | `message_text` / `message_meta` / `system_clock` | **原样引用**，不改写 | `intent_card.build_card()` 的 `facts[]` |
| 时间解析 | **本地规则**（正则 + 星期/日期表） | 标 `confidence`；拿不准 → `needs_user`，交人 | `_parse_when` / `_parse_clock` |
| 地点 | **城市白名单 + 原文** | **非白名单不补全**，只标低置信 `0.4` | `_parse_where`（`CITIES` 18 城） |
| 意图类型 | 本地动词规则表 | 认不出 → `unknown`，标「没看准，不标」 | `_parse_intent`（`INTENT_RULES`） |
| 长期偏好命中 | **本机记忆文件** `.local-state/memory.json` | **显式写出**「命中哪条、因此改变了什么」 | `_memory_applies` ← `memory_store.prefs()` |
| **车次/班次（S3 方案屏）** | ⚠️ **演示样例**（`source: sample`） | **接真实票务服务前不当作事实** | `shiyi_flow._frame_plan()` 的 `_source: "sample"` |

**一句话**：本作品**不调用任何外部服务**。所有事实要么来自消息原文（原样引用），
要么来自本地规则（标注置信度），要么是**明确标注的演示样例**。

## 2. 申请权限

作品按官方 `capabilities` 机制声明所需能力，**只申请已实现功能需要的能力**（原则见 `AGENTS.md`）。

**主提交 = 根 `bundle/`（脚本应用 `shiyi-live`，`version: 0.8.6`）声明 6 项：**

```json
{ "id": "shiyi-live", "name": "拾意 · 现场造卡", "version": "0.8.6",
  "capabilities": ["storage", "model", "octos.session.history",
                   "matrix.read_messages", "matrix.profile", "matrix.send_message"] }
```

| 能力 | 用途 | 不可用时的行为 |
|---|---|---|
| `model` | 助手当决策核心：出人话标题 / 判该不该提醒 / 定提醒时机 / 写提醒话术 / 给依据 | 助手不在 ⇒ **退到本机规则**，卡照出，并如实标注「识别来源 · 本机规则」 |
| `matrix.read_messages` | 读**绑定房间**消息 → 点一条造卡 | 读不到 ⇒ 停在空状态，**不编**（fail-closed） |
| `matrix.profile` | 读你的名字 → 标出「（你）」 | 取不到 ⇒ 不标，不影响主流程 |
| `matrix.send_message` | 确认后把结论**真发回群**（"记下了"→"办成了"） | 发送失败 ⇒ **如实回退**「只留本机」，不假装成功 |
| `octos.session.history` | 读设备助手会话进记忆盒 | 取不到 ⇒ 记忆盒为空，照常可用 |
| `storage` | 长期记忆写在应用自己的存储里（`memory.json`） | 不可用 ⇒ 记忆不落盘，流程照走 |

**另两个形态**：L0 卡片包（`apps/shiyi-card/bundle/`，`version: 0.3.3`）声明 `matrix.send_message` / `octos.session.open` / `octos.turn.start` —— **打开时问本机设备助手一句，答案印在首屏卡**（与本地规则那条**并列**）；助手不在或回合失败 ⇒ 该路径**不求值**，卡片照常显示本地规则版、**不报错**（fail-closed）。系统 app（`octos/`，`version: 0.3.11`）另有 `glance` 等（卡进系统快览屏 + 到点提醒）。

- **不申请网络**：`network.hosts` 为空，解析全在本地，无上报端点。
- **不申请系统存储权限**：记忆只写在**作品自己的应用内存储**（`memory.json`，纯本地文件，不碰系统日历/通讯录/其他应用）。
- **不建账号 / 不登录**：`matrix.send_message` 只发到**你导入时绑定的那个房间**；不收集设备标识。

## 3. 隐私处理

详见 [`PRIVACY.md`](../PRIVACY.md)（`listing.privacy_policy_url` 指向它）。要点：

- 全程在**你的设备上**处理：**不上传、不采集、不统计**（无埋点、无上报）。
- **不建账号**、不要求登录、不收集手机号/邮箱/设备标识。
- **不擅自执行**任何写操作，**不把数据交给第三方**。
- 记忆**可读、可改、可删**，随应用卸载一并消失，无云端副本。

## 5. 用户授权 / 拒绝 / 失败时的行为

### 5.1 授权（每一步都必须过用户）

**默认不执行**。每个决策点都停在一张待确认卡上，用户点确认才推进：

| 决策点 | 授权动作 | 未授权时 |
|---|---|---|
| 识别后 | 「对，就是这件事」 | 停在识别屏，不推进 |
| 追问后 | 「就按这个查」 | 不推进（可 `deferred` 挂起） |
| 方案前 | 「就要第一班」 | 停在方案屏 |
| 记忆前 | 「记下」 | 停在记忆屏，**不写盘** |

### 5.2 拒绝（用户说"不"）

| 用户动作 | 事件 | Agent 行为 |
|---|---|---|
| 识别不对 | `intent.corrected` | 回重读 / 转人工改，**不硬推** |
| 追问先不答 | `ask.deferred` | **挂起**，等人回来，不替用户默认 |
| 方案不满意 | `plan.another_round` | **重排一版**，不强推原方案 |
| 这次不记 | `memo.skip` | **一个字节都不写**（文件 sha 不变，已断言），但流程照走；回执明说「这次什么都没写进本机记忆」 |
| 单条不管 | （卡上"不管它"出口） | 丢弃该条，无副作用 |

### 5.3 失败（出错时）

| 失败类型 | 表现 | 处理 |
|---|---|---|
| **包未签名** | 宿主 `refused: app shiyi is unsigned…` | **本作品卡片一张都不渲染**（fail-closed）；宿主在窗口里画**它自带的拒绝说明页**（含 refused 原文），日志留证（`build/_evidence/neg_unsigned.log` + `neg_unsigned.png`） |
| **包被篡改** | 宿主 `refused: bundle digest … does not match…` | 同样**本作品卡片零渲染**；内容寻址校验兜底（`build/_evidence/neg_tampered.log` + `neg_tampered.png`） |
| **解析拿不准** | 字段 `confidence` 低 / `needs_user=true` | **不猜**，交回用户确认（或出追问卡） |
| **指代未解析** | 「那个」等指代词 | **一律不猜**，出追问卡当面问（`AMBIG_REFS`） |

> 判据说明：**"渲染"指本作品卡片**是否被准入。宿主日志只认 `admitted <app> <ver>`（准入成功）；
> 被拒只打 `refused:`、**绝不打 `admitted`**。⚠️ 不能用 `[SPLASH] eval` 当判据——宿主被拒后
> 画的**自带拒绝页**也会打这一行，那不是本作品的卡片。见 `build/verify_flow.py::card_was_admitted()`。

**共同原则**：**宁可停下来说"还没定"，也不编一个看起来像样的答案。**

### 5.4 记忆的写入（真读写，不是印上去的）

作品把"长期记忆"放在本机一个 JSON 文件里，不是一个写死的常量。存的、取的、不写的，
都是可核验的：

| 时刻 | 文件发生什么 |
|---|---|
| 首次运行 | 文件不存在 → 用内建初始值播种，落盘并标注 `seeded_from: "builtin_initial"`（不假装用户早就教过它） |
| 点「记下」 | `places[地点]` 被写入（默认出发时段 / 出发地 / **来源消息** / 时间戳），`log` 追加一条 |
| 点「这次别记」 | **一个字节都不写**（`verify_flow.py` 断言文件 sha 前后一致） |
| 再跑一遍 | 读得到上一次写进去的内容（断言 `memory_is_effective`） |

内容示意（`places` 一段）：

```json
{ "places": { "深圳": { "default_depart": "早班", "from": "家里",
                        "learned_at": "2026-09-27T12:50:23",
                        "learned_from": "下周三我得去趟深圳", "room": "家庭群" } } }
```

**为什么重要**：之前"长期记忆"存在代码常量里，卡上那句「记得你的老规矩」其实
没有出处。现在它有出处了 —— 评委不必相信我们，打开那个文件即可核。
这也是官方「结果核验」轴上本作品的正面回答。
