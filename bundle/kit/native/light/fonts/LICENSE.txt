fonts/shiyi.ttf — provenance and license
========================================

This file is a subset covering only the CJK / fullwidth characters this
bundle actually renders, taken from the Chinese typeface that makepad_widgets
ships as its built-in font.

Source typeface: LXGW WenKai (written in Chinese as the two characters for
"glow-gull" + "literary"), Copyright (c) 2021 the LXGW WenKai Project Authors,
released under the SIL Open Font License, Version 1.1 (SPDX: OFL-1.1).

This subset is redistributed under the same OFL-1.1 terms. Only the character
set was reduced; no glyph outlines were altered, and the original family name
is retained, as this is an unmodified subset rather than a redesign.

It lives in the bundle because the hub structural admission requires a card
kit font to be a bundled file, so the font travels with the app instead of
being loaded from the host at runtime.
